## Getting Started

### Prerequisites

Install:
- Java Development Kit (JDK) 21
- Apache Tomcat 11
- Eclipse IDE with Java/web development support

### Run in Eclipse

1. Clone or download this repository.
2. Open Eclipse and choose **File → Import → Existing Projects into Workspace**.
3. Select the project folder.
4. Make sure the project uses **JDK 21** and the configured **Tomcat 11** runtime.
5. Add the project to your Tomcat server in Eclipse.
6. Start the server and open the application URL shown in Eclipse's Console or server view.

The exact URL and deployment steps may depend on the web components and context path configured in the source code.

## Usage

Once the application is deployed, open its URL in a browser and use the feedback form if that functionality is implemented in the source code.
